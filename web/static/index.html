SnapLocate — Python standard library only, no build step, no framework. All ranking weights are untuned hand-picked values; any accuracy figure comes from a small hand-built issue set and is not comparable to MM-IssueLoc, SWE-bench M or any published benchmark. The bounding-box convention is read from the API at runtime, never hard-coded in this page. A result replayed from cache is always labelled as a replay.
